# Demo pilot hoàn phí LogiX-VN

Mở `dist/index.html` trong trình duyệt. Demo dùng dữ liệu giả lập và chạy trên trình duyệt.

| Yêu cầu | Kịch bản |
| --- | --- |
| RF-70012 | Duyệt hoàn nội địa thành công. Sau khi hoàn, nút gửi lại kiểm tra chặn giao dịch trùng. |
| RF-70018 | Xem lại và sửa số tiền hoàn hàng nặng. |
| RF-70023 | Quốc tế ngoài phạm vi, chuyển CSKH. |
| RF-70031 | Sổ cái trả lỗi 503, chuyển nhân viên đối soát. |
| RF-70035 | Đối tác có điều khoản riêng, chuyển CSKH. |

Các chỉ số tổng hợp lấy từ hồ sơ E1. Tình huống demo và nhật ký của từng yêu cầu dùng dữ liệu mô phỏng riêng.
